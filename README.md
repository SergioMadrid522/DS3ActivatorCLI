1. make a build
   ```bash
   swift build -c release
   ```
2. run the next command:
   ```bash
   sudo ./.build/release/DS3ActivatorCLI
   ```
   then write your password
3. your ps3 controller is working!, you can verify the connection using this gamepad test (Click here)[https://webcammictest.com/es/gamepad/]

**NOTE**: Once you run it you can stop the execution and keep using your ps3 controller like always on your mac
